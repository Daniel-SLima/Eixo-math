# Eixo Math

**Eixo** é um projeto de aprendizagem matemática interativa voltado, inicialmente, para a progressão de **Matemática Básica → Pré-Cálculo → Cálculo I**.

O objetivo não é criar um quiz com aparência de jogo, mas um ambiente no qual o estudante realmente desenvolva matemática: escrevendo expressões, resolvendo problemas linha por linha, usando rascunho, interpretando gráficos, recebendo feedback pedagógico e aplicando conceitos em situações interativas.

## Princípios centrais

- O aluno deve **resolver**, não apenas selecionar respostas.
- O raciocínio matemático deve poder ser desenvolvido **linha por linha**.
- Diferentes caminhos matematicamente válidos devem ser aceitos.
- O aplicativo terá **Caderno Matemático**, **Teclado Matemático** e **Rascunho** como sistemas distintos.
- Ferramentas matemáticas são apresentadas progressivamente e ensinadas antes de serem exigidas.
- Gráficos e animações devem explicar e confirmar a matemática, não substituir o cálculo.
- O sistema deve identificar lacunas de pré-requisitos.
- Gamificação deve surgir da aplicação da matemática, não de recompensas artificiais desconectadas.
- O conteúdo deverá respeitar direitos autorais e priorizar materiais abertos, de domínio público ou exercícios próprios/adaptados.
